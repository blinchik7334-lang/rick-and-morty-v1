# Rick and Morty Portal Technology — Fabric 1.20.1

Прототип мода для Minecraft 1.20.1 / Fabric / Java 17.

## Четыре пушки
- `portal_gun` — обычная портальная пушка Рика (зелёная тема).
- `prime_portal_gun` — пушка Рика Прайма (зелёный портал, повышенный множитель).
- `evil_morty_portal_gun` — пушка Злого Морти (жёлтый портал).
- `kid_portal_gun` — детская версия (зелёный портал, пониженный множитель). Вместо жидкости в ней анимированный зелёный шар ки: пульсирует, закручивается, вокруг летают искры, по шейке бежит импульс.
  Анимация: `textures/item/kid_portal_gun.png` (16 кадров лентой) + `.png.mcmeta`. Пересборка: `python3 tools/generate_kid_gun_animation.py` (скорость — `FRAMETIME` в скрипте).

У пушки Рика Прайма в текстуре вместо резервуара с жидкостью изображено яркое зелёное энергетическое ядро с электрическими разрядами.

## Одежда персонажей
Для каждой пушки есть свой комплект из 4 предметов (надеваются как броня, защита как у кожаной):

| Персонаж | Причёска | Верх | Низ | Обувь |
|---|---|---|---|---|
| Рик | `rick_hair` | `rick_coat` (белый халат) | `rick_pants` | `rick_shoes` |
| Рик Прайм | `rick_prime_hair` | `rick_prime_coat` (серый халат, зелёные манжеты) | `rick_prime_pants` | `rick_prime_shoes` |
| Злой Морти | `evil_morty_hair` (с повязкой на глазу) | `evil_morty_coat` (чёрный пиджак, жёлтая рубашка) | `evil_morty_pants` | `evil_morty_shoes` |
| Морти | `morty_hair` | `morty_coat` (жёлтая футболка) | `morty_pants` (синие) | `morty_shoes` (белые кроссовки) |

Всё лежит во вкладке творческого режима «Рик и Морти» (туда же добавлены пушки). Выдать вручную: `/give @s rickmortyportal:rick_coat`.

Текстуры брони лежат в `assets/minecraft/textures/models/armor/rickmorty_*_layer_1|2.png`. Их и иконки можно пересобрать командой `python3 tools/generate_clothing_textures.py` после правки палитр в скрипте.

## Управление в текущем прототипе
1. Возьми пушку в руку.
2. Используй ПКМ по блоку, чтобы поставить портал A.
3. Используй ПКМ по другому блоку, чтобы поставить портал B.
4. Подойди к порталу — тебя перенесёт к парному порталу.
5. ПКМ в воздух по пушке сбрасывает пару порталов.

## Сборка
Нужны JDK 17 и Gradle 8.x:
`gradle build`

Готовый JAR появится в `build/libs/`.

## Важно
Это стартовый игровой прототип: порталы пока представлены невидимыми зонами телепортации, без круглой анимированной рамки, звуков, отдельных 3D-моделей и уникальных рецептов. Четыре предмета зарегистрированы в коде; перед релизом нужно добавить текстуры/модели, рецепты и протестировать сборку в конкретной среде Fabric.
